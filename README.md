# Gurdwara Discovery — Prototype V0.8.1

This is a UX correction to V0.8.

## Fixed on the post-answer reveal screen
- **Visited** and **Want to Visit** controls are back directly on the answer/reveal page.
- Guru names are clickable on the reveal page.
- Key place names are clickable on the reveal page.
- Historical text uses the same entity-linking system as the full Gurdwara profile.
- Added a compact **Explore People & Places** section after the educational content.
- The location under the Gurdwara name can open its place profile.
- The full-profile button remains available for the deeper heritage/pilgrimage view.

The richer linked experience now starts immediately after answering a question instead of requiring the user to open the full profile first.
